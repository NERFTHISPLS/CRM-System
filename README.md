# Tasks Tracker App

Веб-приложение для управления списком задач с возможностью создания, редактирования, удаления и отслеживания выполнения задач.

## Функциональность

- Просмотр списка задач
- Добавление новых задач
- Редактирование существующих задач
- Удаление задач
- Отметка выполнения задач
- Фильтрация задач (все, активные, выполненные)

## Система аутентификации и авторизации

- Регистрация новых пользователей
- Вход в систему
- Автоматическое обновление токенов
- Защищенные маршруты
- Доступ по роли (USER, MODERATOR, ADMIN)

## Управление пользователями (для администраторов и модераторов)

- Просмотр списка пользователей
- Просмотр и редактирование профилей пользователей
- Управление ролями
- Блокировка / разблокировка пользователей
- Удаление пользователей из системы

## Технологии

- React 19, TypeScript
- Стилизация: SCSS, antd
- HTTP клиент: axios
- Роутер: react-router
- State Management: Redux Toolkit
- Сборка: vite

## Установка и запуск

### Предварительные требования

- node.js v22+
- npm

### Установка

- Установить все файлы из репозитория
- Находясь в корне проекта, установить зависимости `npm install`

### Запуск

- Находясь в корне проекта, написать `npm run dev`
- Приложение будет доступно по адресу `http://localhost:5173`

### Сборка для прода

`npm run build`
